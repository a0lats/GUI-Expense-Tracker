# GUI Expense Tracker

## Description
A Python desktop application for tracking personal expenses.  
It allows users to:
- Log expenses by category  
- View a list of all recorded expenses  
- Visualize spending patterns with charts  

This project demonstrates the use of Tkinter for GUI design and Matplotlib for data visualization.

---

## Technologies
- Python  
- Tkinter (GUI)  
- Matplotlib (charts)
